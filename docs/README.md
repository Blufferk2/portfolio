# Documentación Portfolio Dídac Soler

Esta carpeta contiene toda la documentación del proyecto de portfolio personal.

## Archivos

| Archivo | Propósito | Cuándo consultarlo |
|---------|-----------|-------------------|
| **PRD.md** | Requisitos del producto | Para entender QUÉ se construye y POR QUÉ |
| **PROJECT.md** | Decisiones técnicas | Para entender CÓMO está estructurado |
| **WORKFLOW.md** | Fases de desarrollo | Para saber EN QUÉ FASE estamos y qué sigue |
| **CLAUDE.md** | Instrucciones para Claude Code | Copiar a la raíz del repo al empezar |

## Cómo usar estos archivos

### Para Dídac
- Consulta `WORKFLOW.md` para saber qué fase toca
- Usa `PRD.md` como referencia si necesitas recordar decisiones
- Actualiza los documentos si hay cambios importantes

### Para Claude Code
- `CLAUDE.md` va en la raíz del repositorio
- Consulta `PRD.md` y `PROJECT.md` antes de implementaciones grandes
- Sigue las fases de `WORKFLOW.md` en orden

## Setup inicial

1. Crear repositorio en GitHub
2. Copiar `CLAUDE.md` a la raíz del repo
3. Guardar el resto de docs en `/docs` o similar
4. Empezar con Fase 0 del `WORKFLOW.md`
